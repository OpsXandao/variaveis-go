# 🧪 Variáveis em Go

Este repositório contém exemplos simples de declaração e uso de variáveis na linguagem [Go (Golang)](https://go.dev/), com foco em aprendizado inicial da sintaxe, tipagem e boas práticas.

## 📌 Conteúdo

- Tipos primitivos: `string`, `int`, `bool`, `float64`
- Declaração com `var` (tipagem explícita)
- Declaração com `:=` (inferência de tipo)
- Execução de um programa básico em Go
